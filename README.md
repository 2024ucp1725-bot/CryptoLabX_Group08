# CryptoLabX

## Cryptography Laboratory - Assignment 1

CryptoLabX is a modular cryptography and cryptanalysis toolkit
being developed as part of the Cryptography Laboratory.

## Team Members

- Member 1: BHAWANA KUMARI
- Member 2: BHARAT SAINI

## Project Structure

- classical/ - Classical cryptography modules
- attacks/ - Cryptanalysis and attack modules
- math/ - Mathematical utilities
- modern/ - Modern cryptography modules
- analysis/ - Text and cryptographic analysis
- datasets/ - Input text datasets
- outputs/ - Generated output and log files
- docs/ - Project documentation
- tests/ - Test files
- utils/ - Utility functions
- main.py - Main command-line interface

## Current Features

- Menu-driven command-line interface
- Dataset text analysis
- Character, word and line counting
- Letter frequency analysis
- Execution logging

## Future Modules

- Classical ciphers
- Cryptanalysis attacks
- Number theory utilities
- Modern cryptography
- Security analysis
- Automated testing

## Requirements

- Python 3
- Git
- Linux/Ubuntu recommended
