# Observations

1. Shift Cipher encryption and decryption were implemented successfully.
2. Brute-force attack tested all 26 possible keys.
3. Dictionary scoring ranked possible plaintexts according to English words.
4. Chi-Square analysis compared letter frequencies with expected English
   frequencies.
5. Dictionary scoring is useful when recognizable English words are present.
6. Chi-Square analysis is more suitable for longer ciphertexts.
7. The two methods can produce different predictions for short messages.

# Conclusion

The Shift Cipher was successfully analyzed using brute-force dictionary
scoring and Chi-Square frequency analysis.

The experiment demonstrates how classical cryptanalysis techniques can be
used to recover the key of a Shift Cipher without directly knowing the key.
